# 📊 Sales & Business Analytics Dashboard  
### (Atliq Hardware – Power BI & SQL)

This project is a **Business Intelligence and Data Analytics solution** built using **SQL and Power BI** on a realistic corporate sales dataset (Atliq Hardware).  
It demonstrates how raw business data can be transformed into **interactive dashboards and meaningful insights** for management and decision-making.

---

## 🧠 Project Objective

The goal of this project is to:
- Analyze sales and business performance  
- Identify trends across products, customers, and regions  
- Help management make **data-driven decisions**  

This simulates how **real companies use BI tools** to understand their business.

---

## 📂 Dataset

The dataset represents **Atliq Hardware**, a fictional but realistic company with:
- Products  
- Customers  
- Regions  
- Sales transactions  

The data is provided in the form of a **SQL database dump**, which is restored and used as the backend for Power BI.

---

## 🛠 Tools & Technologies Used

- **SQL** – Data storage, queries, and data preparation  
- **Power BI Desktop** – Dashboard creation and visualization  
- **Power BI Data Model** – Relationships between tables  
- **Business Analytics Techniques**

---

## ⚙️ What This Project Includes

This repository contains:

| File | Description |
|------|-------------|
| `db_dump.sql` | SQL dump file containing the full Atliq Hardware dataset |
| `PowerBI_automated_dashboard_for_Sales.pbix` | Interactive Power BI dashboard built on top of the SQL data |

---

## 📊 Dashboard Capabilities

The Power BI dashboard provides insights such as:
- Total and monthly sales  
- Top-selling products  
- Revenue by region  
- Customer performance  
- Sales trends over time  

These visualizations allow users to quickly understand:
> Where the business is performing well and where improvements are needed.
